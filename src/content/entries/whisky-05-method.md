前四章讲的是威士忌从哪里来、怎么做出来。这一章把它们落到杯子里：怎样系统地品鉴一杯威士忌，把喝到的东西和前面学到的原料、工艺、木桶、产区联系起来。

## 准备

### 酒杯

- **郁金香形闻香杯**最合适，比如格兰凯恩杯（Glencairn）或雪莉酒的 copita 杯。杯肚宽、杯口收窄，能把香气聚拢在杯口。
- 宽口的古典杯适合加冰随意饮用，但香气散得快，不适合认真品鉴。

### 环境与分量

- 选择没有强烈气味的环境，避免香水、香烟和浓烈的食物。
- 每次倒 15–30 毫升即可，酒在杯中占一小部分，留出空间让香气聚集。
- 准备清水和无味的苏打饼干，用来清口。

### 品鉴顺序

一次品鉴多款时，一般从轻到重：先轻盈的，后厚重的；先低度的，后高度的；**泥煤酒放在最后**，因为它的烟熏味会长时间影响味觉和嗅觉。

## 第一步：观色

把杯子倾斜，对着白色背景观察：

- **清澈度**：应该清澈透亮。未经冷凝过滤的酒加水或遇冷时可能轻微浑浊，这是正常现象。
- **颜色**：从浅稻草色、金黄、琥珀到深红褐色。
- **挂杯**：轻轻晃动后沿杯壁流下的"酒泪"，和酒精度、糖分、黏度有关。

要记住上一章讲过的：苏格兰威士忌允许添加焦糖色，所以**颜色深浅不能用来判断年份或木桶**，只能作为参考。

## 第二步：闻香

闻香是品鉴中信息量最大的一步。

- 先把杯子放在下巴附近，再慢慢靠近鼻子。威士忌酒精度高，一下子凑太近，酒精会刺激鼻腔，让你什么都闻不到。
- 闻的时候可以微微张开嘴，有助于减轻酒精的刺激感。
- 闻几次、每次间隔一会儿，第二次、第三次往往能闻到第一次被酒精盖住的香气。
- 轻轻晃杯会释放更多香气，但不要过度。

试着从大类入手描述：

| 风味大类 | 常见描述 | 可能的来源 |
| --- | --- | --- |
| 谷物 | 麦芽、饼干、粥、坚果 | 原料、浑浊麦汁、较宽的切点 |
| 果香 | 青苹果、梨、柑橘、热带水果 | 发酵产生的酯类 |
| 干果 | 葡萄干、无花果、椰枣 | 雪莉桶等葡萄酒桶 |
| 花香 | 鲜花、石南花、香水 | 发酵、轻盈的蒸馏风格 |
| 甜香 | 香草、蜂蜜、焦糖、太妃糖 | 美国橡木桶 |
| 木质与香料 | 橡木、肉桂、丁香、胡椒 | 欧洲橡木、长时间陈年 |
| 泥煤 | 烟熏、篝火、药水、碘酒、海水 | 泥煤烘干的麦芽 |
| 硫味 | 火柴、橡胶、肉味 | 铜接触少的蒸馏，部分雪莉桶 |

这张表本质上是一个简化版的风味轮。苏格兰威士忌研究机构的前身 Pentlands 在 20 世纪 70 年代末设计的"Pentlands 风味轮"，是业内描述威士忌风味的经典工具。

## 第三步：品尝

- 先喝一小口，让酒在口腔里停留几秒，铺满整个舌面。有人会轻轻"咀嚼"，让酒接触口腔各个部位。
- 第一口往往被酒精冲击占据，第二口开始才能准确感受风味。

关注这些方面：

- **甜度**：是干还是甜。
- **酒精感**：温暖还是灼烧，是否和酒体协调。
- **酒体与口感**：轻盈还是饱满，油润、顺滑、粗糙还是干涩。
- **风味**：和闻到的香气是否一致，有没有新的风味出现。
- **发展**：风味在口中是否随时间变化。

## 第四步：余韵

咽下之后，风味持续多久，是什么样的风味：

- **长度**：短（几秒）、中、长（一分钟以上）。
- **质地**：是温暖的香料、持久的烟熏，还是变得苦涩、干燥。

余韵的长度和质量，是判断一款酒品质的重要依据。

## 要不要加水

加几滴水是很多专业品鉴者的习惯，尤其是对高酒精度的酒：

- 降低酒精对鼻腔和口腔的刺激，让其他风味更容易被感知。
- 研究发现，酒精浓度降低时，愈创木酚这类带烟熏风味的分子会更多地聚集到液面附近，更容易释放出来（Karlsson 与 Friedman，2017 年发表于《Scientific Reports》）。这为"加水打开香气"提供了一种解释。

做法是用滴管或小勺**一次加几滴**，闻一闻、尝一尝再决定是否继续加。先净饮，再加水，对比前后的变化，是很好的练习方式。

加冰会让香气明显收敛，适合消暑畅饮，但不适合品鉴。

## 系统品鉴法

如果想更系统，可以参考 WSET（英国葡萄酒与烈酒教育基金会）烈酒课程的系统品鉴法，它把品鉴分成四部分：

1. **外观**：清澈度、颜色。
2. **香气**：强度、香气特征。
3. **口感**：甜度、酒精感、风味强度、风味特征、余韵。
4. **结论**：品质等级。

评价品质时，可以用四个维度来思考：

- **平衡**：甜、酒精、木头、风味之间是否协调。
- **长度**：余韵是否持久。
- **强度**：风味是否清晰有力。
- **复杂度**：是否有多层次的风味，并且在杯中不断变化。

## 记录与练习

一个简单的品鉴记录模板：

| 项目 | 记录 |
| --- | --- |
| 酒款 | 名称、酒厂、年份、酒精度、桶型 |
| 外观 | 颜色 |
| 香气 | 净饮时，加水后 |
| 口感 | 甜度、酒体、风味 |
| 余韵 | 长度、风味 |
| 结论 | 平衡、长度、强度、复杂度，以及你自己的喜好 |

练习建议：

- **对比品鉴**：同一酒厂不同桶型、同一产区不同酒厂、同一酒款不同年份，对比最容易建立认知。
- **回到原理**：喝到明显的香草和椰子，想想是不是美国橡木；喝到干果和香料，想想是不是雪莉桶。把感官体验和前几章的知识对应起来。
- **区分"描述"和"喜欢"**：先客观描述有什么，再说自己喜不喜欢，这两件事要分开。
- **控制饮酒量**：品鉴时可以准备吐酒杯，尤其是一次品鉴多款时。

## 本章要点

- 用郁金香形闻香杯，每次 15–30 毫升，从轻到重，泥煤酒放最后。
- 按观色、闻香、品尝、余韵的顺序进行，闻香时保持距离、微张嘴。
- 颜色可能来自焦糖色，不能用来判断年份。
- 加几滴水能降低酒精刺激、释放香气，先净饮再加水对比。
- 用平衡、长度、强度、复杂度评价品质，并把描述和喜好分开。
