酒标上的"单一麦芽""调和""波本""单一壶式蒸馏"，并不是营销用语，而是有法律定义的类别。学威士忌的第一步，是搞清楚这些名字分别代表什么原料、什么做法。

## 什么是威士忌

最宽泛的定义是：**以谷物为原料，经过糖化、发酵、蒸馏，并在木桶中陈年的烈酒**。

具体到各个国家和地区，法律会对原料、蒸馏度数、木桶、陈年时间和装瓶度数做出更严格的规定。同样叫"威士忌"，苏格兰、美国、日本的要求并不一样。

## 原料

### 大麦与发芽

大麦是苏格兰麦芽威士忌唯一的谷物原料。但大麦里储存的是淀粉，酵母无法直接利用，所以要先**发芽**：

1. **浸泡**：让大麦吸水。
2. **发芽**：大麦开始萌发，产生能把淀粉分解成糖的酶（淀粉酶）。
3. **烘干**：在适当时机加热停止发芽，保留住这些酶，得到麦芽。

如今大多数酒厂直接从专业麦芽厂购买麦芽，只有少数酒厂还保留自己的地板发芽。

### 泥煤

泥煤是在潮湿地区经过数千年堆积、部分碳化的植物残体。在烘干麦芽时燃烧泥煤，烟雾中的酚类物质会附着在麦芽上，最终在威士忌里表现为烟熏、药水、海水、焦油般的风味。

麦芽的泥煤程度常用酚值（ppm，百万分之一）表示。无泥煤麦芽接近 0，重泥煤麦芽常在 40 到 50 ppm 以上。要注意，这是麦芽的数值，经过蒸馏和陈年，酒里最终保留下来的酚类要少得多。

### 其他谷物、水和酵母

- **玉米、小麦、黑麦、未发芽大麦**：用于谷物威士忌、波本、黑麦威士忌和爱尔兰壶式蒸馏威士忌。它们需要借助麦芽中的酶，或经过蒸煮才能糖化。
- **水**：用于糖化、冷却和装瓶前降度。酒厂常强调水源，但它对风味的影响往往不如其他因素大。
- **酵母**：把糖转化为酒精，同时生成大量酯类等风味物质。

## 苏格兰威士忌

依据英国《2009 年苏格兰威士忌法规》（Scotch Whisky Regulations 2009），苏格兰威士忌必须：

- 在苏格兰用水和发芽大麦（可加入其他谷物）制作，只能依靠麦芽自身的酶糖化，只能用酵母发酵；
- 蒸馏后酒精度低于 94.8%，保留原料的风味；
- 在苏格兰境内、容量不超过 700 升的橡木桶中陈年至少 3 年；
- 除了水和普通焦糖色（E150a），不得添加其他物质；
- 装瓶酒精度至少 40%。

法规定义了五个类别：

| 类别 | 原料 | 蒸馏方式 | 说明 |
| --- | --- | --- | --- |
| 单一麦芽威士忌 | 只用发芽大麦 | 壶式蒸馏器，分批蒸馏 | 全部来自同一家酒厂 |
| 单一谷物威士忌 | 发芽大麦加其他谷物 | 通常用连续式蒸馏器 | 全部来自同一家酒厂 |
| 调和麦芽威士忌 | | | 多家酒厂的单一麦芽调和 |
| 调和谷物威士忌 | | | 多家酒厂的单一谷物调和 |
| 调和威士忌 | | | 麦芽威士忌与谷物威士忌调和，销量最大 |

## 爱尔兰威士忌

依据爱尔兰相关法律，爱尔兰威士忌必须在爱尔兰岛（包括北爱尔兰）蒸馏，在木桶中陈年至少 3 年。最有特色的类别是**单一壶式蒸馏威士忌**（Single Pot Still）：原料同时使用发芽大麦和未发芽大麦（两者通常各占至少 30%），在壶式蒸馏器中蒸馏。未发芽大麦带来一种辛香、油润的口感。

爱尔兰威士忌常以三次蒸馏著称，但这并不是法律要求。

## 美国威士忌

美国联邦法规对各类威士忌有明确的"身份标准"。最重要的是**波本威士忌**：

- 原料中玉米至少占 51%；
- 蒸馏后酒精度不超过 80%；
- 必须装入**全新的、内壁烧烤过的橡木容器**陈年；
- 入桶时酒精度不超过 62.5%；
- 装瓶酒精度至少 40%；
- 必须在美国生产，但不要求在肯塔基州。

陈年至少 2 年、且不添加色素和调味剂的，可以标为**纯波本**（Straight Bourbon）。

其他常见类型：

- **黑麦威士忌**：黑麦至少占 51%，其余要求与波本类似，风味更辛辣。
- **田纳西威士忌**：基本符合波本的要求，田纳西州法律还要求在入桶前用枫木炭过滤新酒，这一步叫"林肯郡工艺"，能让酒体更柔顺。

"必须使用全新橡木桶"这一条，对全世界的威士忌都有深远影响：用过一次的波本桶会大量流向苏格兰等地，成为那里最主要的陈年容器。第三章会详细讲。

## 日本威士忌

日本酒税法对威士忌的定义一度相当宽松，市面上不少"日本威士忌"其实混入了进口原酒。2021 年，日本洋酒酒造组合发布了行业自律标准，并给出了到 2024 年的过渡期。按照这一标准，标示为"日本威士忌"的产品需要：

- 原料使用麦芽，可以加入其他谷物，使用日本国内的水；
- 糖化、发酵、蒸馏都在日本国内完成；
- 在日本国内、容量不超过 700 升的木桶中陈年至少 3 年；
- 在日本国内装瓶，装瓶酒精度至少 40%。

## 看懂酒标上的年份

- **年份标示**：比如"12 年"，指的是瓶中**最年轻**的那部分原酒至少陈年了 12 年，瓶里可能还有更老的酒。
- **无年份标示**（NAS，No Age Statement）：没有标注年份。它不一定代表品质差，可能只是酒厂希望在调配上更自由。
- 威士忌装瓶后不会继续陈年，一瓶 12 年的酒放 10 年还是 12 年。

## 本章要点

- 威士忌是谷物经糖化、发酵、蒸馏并在木桶陈年的烈酒，各国法规对细节有不同要求。
- 发芽让大麦产生分解淀粉的酶；泥煤烘干带来烟熏风味，用酚值衡量。
- 苏格兰威士忌：苏格兰境内、橡木桶陈年至少 3 年、装瓶至少 40%，分为五个类别。
- 波本：玉米至少 51%、全新烧烤橡木桶、装瓶至少 40%。
- 年份标示的是瓶中最年轻的原酒。
